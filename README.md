# Math Calculator

This Python program is a calculator that allows users to solve different types of math problems, including basic operations, geometry, algebra, order of operations, and unit conversions. To use it, run the program and choose an option from the main menu by entering its number. Follow the instructions on the screen and enter the equation or numbers requested. After getting your answer, type continue to solve another problem or menu to return to the main menu. To exit the program, enter 0. Make sure to enter valid numbers and mathematical symbols when solving problems.
